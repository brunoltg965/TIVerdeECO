# ♻️ EcoDescarte - Mapeamento de Lixo Eletrônico (Green IT)

Aplicação desenvolvida para o projeto acadêmico de Gestão de Tecnologia da Informação. O EcoDescarte mapeia pontos de coleta de lixo eletrônico na Baixada Fluminense, conectando cidadãos à logística reversa e promovendo a sustentabilidade (ODS 11, 12 e 13 da ONU).

## 🛠️ Tecnologias
- **Frontend:** React.js, Vite, Tailwind CSS
- **Design:** Dark mode corporativo com destaques em verde neon
- **Ferramentas de Pesquisa:** Escala Likert integrada para feedback

## 🚀 Como executar localmente
1. Instale as dependências: `npm install`
2. Rode o projeto: `npm run dev`
